A newspaper front page summing up the world news of **Sunday 22 November 2026**, drawn entirely in code by `main.ts` (Node 22, standard library only). It implements its own PNG encoder (IHDR/IDAT/IEND with CRC32) and its own 5x7 bitmap font, and writes a deterministic 1024x1024 PNG to `$MAKEFUN_OUTPUT_DIR/entry.png`. Run it with:

```
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
